# ❓ FAQ

## Do I need a legitimate Dragon's Dogma 2 copy?

Yes.

This method only works with legitimate installations.


---

## Can I still play online?

Yes.

Online and offline play both work normally.

---

## Does this work with mods?

Yes.

DLC-required mods should work normally if the DLC files are installed correctly.

---

## Why are my DLCs disappearing?

Usually caused by Dragon's Dogma 2 updates.

To fix:

1. Run the unlocker
2. Configure Dragon's Dogma 2 again
3. Repair the game
